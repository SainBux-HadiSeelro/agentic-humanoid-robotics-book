## Self-Assessment Questions

1. What are the main advantages of Unity over Gazebo for visual fidelity?
2. How do you implement realistic lighting in Unity environments?
3. What is the purpose of navigation meshes in robotics simulation?
4. How do you optimize Unity scenes for complex humanoid simulation?
5. What are the key differences between Unity's PhysX and Gazebo's physics engines?

## Answer Guide

1. Unity offers superior rendering quality, advanced lighting systems, and better visual effects for realistic environments.
2. Use directional lights, point lights, light probes, and post-processing effects for realistic illumination.
3. Navigation meshes define walkable areas for pathfinding and robot navigation planning.
4. Use LOD systems, occlusion culling, texture compression, and efficient shaders for optimization.
5. PhysX is optimized for visual rendering while Gazebo's engines are specialized for robotics physics.
